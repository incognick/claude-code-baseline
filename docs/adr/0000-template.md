# ADR-0000: Title in the imperative

- **Status:** Proposed
- **Date:** YYYY-MM-DD
- **Supersedes:** — (or ADR-NNNN, fully / partially)
- **Superseded by:** — (added later by `scripts/adr-supersede.sh`; the *only* edit an accepted ADR ever gets)

## TL;DR

Caveman. Three to five lines, max. No articles, no hedging, no
filler. Someone who reads only this section must still know what we
decided and roughly why. Jargon only if it is the actual name of the
thing.

## Context

What forced a decision. The constraint, the failure, the tradeoff.
Normal prose. Include the thing that was tried and did not work, if
there was one — that is usually the most valuable part.

## Decision

What we are doing. Concrete and specific enough that someone could
implement it without asking a follow-up question.

## Consequences

What this costs. What it rules out. What breaks if we ever want to
undo it. Be honest about the bad parts — an ADR with no downsides
listed is an ADR that was not thought through.

## Alternatives considered

Optional but usually worth it. One line each and why not.
